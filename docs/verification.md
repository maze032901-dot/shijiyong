# 发布前与安装者验收

先用纯虚构 URL、事件 ID、卡片和一张自制测试图片跑自动化测试：`npm test`。自动化覆盖三种凭据的隔离、图片权限、队列重试、补交媒体、模型失败与云端恢复后的补同步；手机离线缓存和 Mac 离线时的命令状态仍须在真机验收。真实链接验收只在安装者自己的部署里进行，不把链接或媒体提交到仓库。

手动全链路：在 Android 抖音复制一条视频链接和一条图文链接；确认云端出现临时卡，Mac 抓取与识别进度可见，成卡后网页和手机都出现对应主题、子卡、必要图片与来源。测试单卡直达、多卡展开、Prompt 复制。让一条抓取失败，确认不会阻塞下一条，并分别试自动有界重试与本地补交媒体。再断开 Mac、短暂断开云端，确认已同步卡片仍可离线查看且失败状态不会误显示为成功。

公开前必须再次检查：没有 `.env`、`runtime/` 个人内容、`data/`、媒体、审核结果、模型、调试 APK、真实作品 ID、个人服务器地址；第三方许可和完整新 Git 历史均已审查。未通过以上任一项，不推送 GitHub。推送保护只能作为额外防线。
